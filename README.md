# Skrzypce – aplikacja (Capacitor)

Kod aplikacji: www/index.html (cały interfejs i logika), baza: schema.sql (ta sama jest wbudowana w index.html).

Android:  npm install  ->  npm run android:setup  ->  npm run android:open  ->  Build APK w Android Studio
iPhone:   wrzuć projekt na GitHub (publiczne repo) -> zakładka Actions -> "Build iOS" -> pobierz skrzypce-ipa -> Sideloadly

Po zmianie www/index.html:  npm run sync  (Android) albo git push (iPhone)
